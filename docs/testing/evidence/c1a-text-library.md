Typed request fields must be present; unknown properties/NUL/oversize inputs are rejected. Body/description whitespace and Unicode are preserved. Source records have no student/activity relationship, grants or delete operation. List DTO omits the body. [API contract](../../backend/api.md#implemented-c1a-text-library-contract--2026-10-28).

The existing noncacheable auth/session/origin/CSRF boundary covers every content route. API path casing is normalized before checks to agree with ASP.NET route matching; uppercase and lowercase negative cases are tested. Two distinct students, anonymous/restricted/revoked sessions cannot read/write known or unknown library resources.

Bilingual library, new/edit form and archived reader use the existing white/navy components. Text renders as escaped React strings/textarea values, including script-like strings. Failed/stale saves retain drafts; stale writes require explicit cancelable discard/reload. Archive warns about unsaved edits and retains saved bytes; restore reopens the same source. Locale changes preserve draft, selector focus, confirmation and pending save, issuing no extra request. Loading/success notices do not overlap. Navigation focus yields to an already-focused language selector. No browser draft persistence or auto-save/recovery promise.
